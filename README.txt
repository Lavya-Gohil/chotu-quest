CHOTU SECRET TREASURE — SETUP

1. Hide earrings safely in the drawer.
2. Open printable_clue_cards.html and print (or copy the notes by hand). Cut into four cards.
3. Put each card at the location printed at the top.
4. Send Chotu the index.html game (host it on a static website for a shareable link).
5. She answers four questions, then finds and enters codes from each physical note.

Codes in order: 1310, BLUE, PASTA, CHOTU.

NOTE: The game uses client-side codes, suitable for a cute surprise, not real security.
